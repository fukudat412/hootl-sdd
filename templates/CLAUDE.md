# このリポジトリでの作業規約（エージェント向け）

このリポジトリは無人のループ（hootl）で開発されている。あなたは1タスクだけを担当し、終わったら終了する。人は不在で、質問には誰も答えない。

## 必ず守ること

1. 渡されたタスクの「書いてよいパス」以外は変更しない。違反すると内容に関係なく差し戻される。
2. 受け入れ条件1つにつき、少なくとも1つのテストを書く。テスト名に `<タスクID> AC<番号>` を入れる。
3. 次は機械的に検出されて差し戻される:
   - テストの `skip` / `only` / `todo`、`xit` の追加
   - `@ts-ignore` / `@ts-nocheck` / lint 抑止コメントの追加
   - 既存テストの削除
   - 設定ファイル（package.json、tsconfig、biome、vitest、playwright、CLAUDE.md、hootl.toml）の変更
4. 依存パッケージを追加しない（タスクの説明に明記されている場合を除く）。
5. 判断できないことは推測で埋めない。`docs/decisions/` に「判断不能: 〜」と書いて終える。
6. 終わる前に、プロンプトに書かれたゲートを全部実行し、通ることを確認する。
7. コミットはしない（ハーネスが行う）。

## コードの書き方

- 可読性優先。賢い1行より、名前のついた3行。
- 時刻と乱数は引数で注入できるようにする（テストで固定するため）。
- 決定論で済む処理に LLM を使わない。
